## Proposed paragraph (~180 words)

```latex
\paragraph{Axiomatic models and litmus-test synthesis.}
\toolname{}'s methodology comes from memory-consistency-model (MCM) verification. Axiomatic frameworks such as cat~\cite{herdingcats} describe the allowed executions of a program as relations over events, and Alloy~\cite{jackson2002alloy}, backed by the Kodkod model finder~\cite{torlak2007kodkod}, has been used to compare MCMs and find distinguishing tests~\cite{memalloy} and to synthesize complete suites of minimal litmus tests~\cite{lustig,hossain2020transform}. The Check tools (Sec.~\ref{sec:bg-axiomatic}) check implementations against such models, down to RTL~\cite{manerkar2017rtlcheck}. CheckMate~\cite{checkmate} carried this approach to security: it synthesizes exploit litmus tests from happens-before models of an undefended pipeline, and it found new attack variants~\cite{trippel2018meltdownprime}. \toolname{} applies the same minimal-test enumeration to speculation \emph{defenses}. The model encodes a defense's own guarantee (its speculation contract, protection set and transmitters), so every generated test contains a leak shape the defense claims to block. Each test is concretized to x86 and run on the defense's gem5 implementation, which acts as the oracle. In CheckMate, by contrast, the model under study is itself the target.
```
