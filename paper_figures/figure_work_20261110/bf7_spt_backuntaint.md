**LaTeX caption (already in the file):** Three ways SPT's untaint rules make a protected value public (gem5-spt, SpectreSafeFence; hand-written tests, not found by our generated tests). (a) A false `cmov` copies p, yet once a non-speculative load declassifies its output, SPT's backward rule for `mov` untaints its unmoved source s. (b) `inc` reads the CF/OF flags register, so declassifying its result untaints the flags of an older compare on s, and a wrong-path `jb` reveals s<100. (c) An 8-bit write taints only the byte it writes, while the other seven bytes keep s's value. In each test the transmitter leaks while the mispredicted branch is held; the same test without the bug's trigger does not leak.
