
# SimSpect bug catalog (cross-build)

Master index of issues found across every gem5 build + the pipeline. Each entry gives the
**signature**, the **verdict** (real gem5/defense bug vs. pipeline-artifact vs. checker vs. codegen
vs. model-expressivity vs. config/testset), the **provenance** (which run/commit it was seen on),
and **status**. Representative example folders live next to this file; everything else is
cross-referenced to its `claudelog.md` entry / `results/<run>/diagnostics/` + bug `.md` so this stays
a thin index and isn't duplicated.

> **Two views of the same findings:** this file is organized **by gem5 build**.
> [`BUG_TAXONOMY.md`](BUG_TAXONOMY.md) is the same findings organized **by root-cause layer**
> (target / checker / alloy / pipeline) — the triage drill-down + summary matrix.
> [`graphs/`](graphs/) holds per-(testset × implementation) hit-attribution charts colored by category
> (`python3 graphs/make_graphs.py` regenerates them).

Legend — verdict: 🔴 real gem5/defense bug · 🟠 checker artifact · 🟡 pipeline/codegen/concretization
· 🔵 model-expressivity/enumeration · ⚪ config/testset realizability (not a bug).
Status: ✅ verified · 🛠 fixed · ⏳ open/pending owner.

## Bug scripts (STAGE3_gem5/bugs/)

Since 2026-11-15 (agent bugscripts, Anna: "1 python script per bug to find it, in a way that is very clean") every known hit cause has exactly one Python module in `STAGE3_gem5/bugs/`, and one orchestrator, `STAGE3_gem5/bugs/classify.py`, runs them: disqualifiers first, then real-bug modules, and writes the same files the old classifiers wrote (`classes.jsonl`, `classes_rmw.jsonl`, `first_detection*.json`, `cleanupspec_skip_evidence.json`, eval gate and bucket JSONs), so `firstdet_report.py`, the `uv5_*` scripts and the figure scripts read its output unchanged. Each module's docstring holds the full signature, the evidence pointer and the verdict; its metadata (PAPER_LABEL, DEFENSES, PHASE, VERDICT, ORDER, NEEDS_GEM5) is mirrored in `specs/hit_categories.json` (one entry per module). Shared fact extractors (trace parsers, the SpecLFB per-load tagger) live in `_trace.py` and `_speclfb.py` and decide nothing. The old classifiers (`STAGE3_gem5/timing/{classify_hits,cleanupspec_skip_evidence,classify_cs_rmw,speclfb_analyze}.py`, `runconfigs/twostage_lp/eval_20261110/{eval_gate,bucket_eval}.py`) stay in place as the reference until Anna switches over. Commands: `wiki/state/COMMANDS.md` "Hit attribution". Regression: `_regress.py` (results in the section's last paragraph).

**The paper's 11 bugs.**

- **A-UV1, InvisiSpec** (`a_uv1_invisispec.py`, label `UV1`): an in-window offending `L1D:evict req=specld` that is not H-PAD padding. Real bug, known (AMuLeT). Sub-label `UV1_transient` (`a_uv1_transient.py`): the evicting load never became visible.
- **A-UV3, CleanupSpec** (`a_uv3_cleanupspec_rmw.py`, `UV3`): an otherwise unattributed under_clean item whose events are all write-request fills (L1D ST / L2 GETX) by one never-retired actor at the RMW transmitter's pc, with `cleanup_skip why=nohitinfo`. Real bug, known.
- **A-UV4, CleanupSpec** (`a_uv4_cleanupspec_split.py`, `UV4`): the item's install or victim belongs to a squashed load whose cleanup was skipped `why=split`. Real bug, known.
- **A-UV5, CleanupSpec** (`a_uv5_cleanupspec_overclean.py`, `UV5`): over_clean item where an older committed access hits the squashed load's fill before `cleanup_inv`. Real bug, known. DG-3 option (i) is applied in `_dg3.py` (see below).
- **A-UV6, SpecLFB** (`a_uv6_speclfb_first_load.py`, `UV6`): an in-window load footprint event of the rank-0 (first) speculative load of its squash group with unsafe=0. Real bug, known.
- **UV1, STT xmm4** (`uv1_stt_xmm4.py`, `S1_xmm4`): the gated hit's transmitter slice touches `%xmm4` (`_fv2_slice`). Real bug, new.
- **UV2, ReCon STLF skips the taint check** (`uv2_recon_stlf.py`, A2): rerun evidence shows the transmitter `isTainted=1 isSpeculative=1`, forwarded from a store, ready in the window. Real bug, new. 2026-11-16 (rstltriage): on store-shadow tests the `recon_stlf` analyzer (`triage/rerun_hits_evidence.py`) now takes the window end from the store's `stl_release` even when a branch is held by the timing grid's `resolved` stall (that branch is never a window branch: every E2w-stl record's window is the store alone); it had scored inst-021161 "other" (1 of 9,537 evidence keys affected; branch rows unchanged).
- **UV3, ReCon oldest taint only** (`uv3_recon_oldest_taint.py`, R-SA-8): a br_x gated hit whose faithful GPR twin also hits (bucket "R-SA-8 candidate"); `rsa8_trace.py` evidence confirms per test. Real bug, new (bucket is a candidate class). **Store-shadow confirmation (2026-11-16, rstltriage, row E2w-stl):** `rsa8_trace.py` needs a held branch, which store-shadow tests lack, so `STAGE3_gem5/triage/oldest_taint_replay.py` replays gem5's taint tracker offline over one faithful rerun (Rename/Commit/DelayUnit/IEW flags; gem5's rules incl. std::map insert-no-overwrite, phys flat 16 skip, FP loads never speculative; the replayed insert counts must equal stats.txt `insertedTaints`/`insertedTaintInsts`, `allowlistedTaintsFromTT` and `revealRequests` must be 0) twice: with gem5's oldest-source rule and with a keep-all-sources counterfactual. Confirmed when, under the oldest rule, the transmitter (br_x, ld or RMW) is untainted or released exactly one cycle after an older load O's taint dies, while the counterfactual still carries the annotated bypass load L (speculative until the store's `stl_release`) and the signal precedes `stl_release`. Shape A = X in the delay unit, then released; shape B = never in the delay unit (DECIDE RL-12). Label "R-SA-8 confirmed (store shadow; oldest-source taint replay)" (+ " (ld)", " (main run, no twin, RMW)"), via `classify.py bucket --oldest-taint`; other rows keep the candidate label. The evidence names the merge instruction and how O entered it: a gem5 flags (CC) read, a pure move reading its old destination (`mov`, `movq gpr->xmm` low half), or a real data operand.
- **UV4, SpecLFB ROB walk order** (`uv4_speclfb_walk_order.py`, `walk_order`): rank ≥ 1 load, unsafe=0, prevnounsafe=1 at translation, not jmp_shadow. Real bug, new.
- **UV5, SpecLFB jmp shadow** (`uv5_speclfb_jmp_shadow.py`, `jmp_shadow`): rank ≥ 1 load never CUSL/mUSL with a direct `JMP_I`/`CALL_NEAR_I` between the squashing branch and it. Real bug, new.
- **UV6, VP/squash race** (`uv6_vp_squash_race.py`): `diag_stt_vp_squash_race.py` rerun verdict `stt_vp_squash_race` (real access after the branch resolution, before the squash). Real bug, new. A count from records alone (race_scan.py) is still DECIDE BC-1 and is not encoded.

- **EM_upgrade** (`cs_em_upgrade.py`): the same skip with a squashed upgrader; refined into **EM_rmw** (`cs_em_rmw.py`, the test's own RMW = CS-EM) and **EM_other** (`cs_em_other.py`). UV3 family, verdict pending (DECIDE CleanupSpec E→M).
- **UV3_other_actor** (`cs_uv3_other_actor.py`): the A-UV3 event chain by an actor that is neither the RMW transmitter nor the padding. Reported only.
- **R-SA-13** (`r_sa13_recon_sse_load.py`): ReCon loses the taint through an SSE-load producer (static slice class, twin held, "via FP elsewhere", untainted transmitter without a twin). Real ReCon behaviour, not a paper bug. 2026-11-16 (rstltriage): also "R-SA-13 (annotated load is an SSE load; replay[, RMW])", from `oldest_taint_replay.py` evidence (`load_fp`: every annotated bypass load is an SSE load, gem5 STL_CHECK `isSpeculative=0`, no taint in the keep-all-sources replay); the static slicer misses these through an `idiv` on the slice. - **R-SA-9** (`r_sa9_recon_twin_untaint.py`): main-run R-SA-13, twin hit with an untainted transmitter and no reveal (E2LT-1).

**Disqualifiers and artifacts.**

- **Data-obtained gate** (`disq_data_obtained.py`, `disq_not_obtained(<fate>)`): check_ld's canonical gate (CLAUDE.md "Leak criteria"). Checker false positive.
- **SETUP block** (`disq_setup_block.py`, `excluded_SETUP:*`): under cache_setup `full`, events of the harness's own L1D sweep. Harness artifact.
- **H-PAD text end** (`disq_hpad_text_end.py`, `excluded_HPAD:*`): events at or past `.text` end (zero padding reached by wrong-path fetch). Harness artifact.
- **H-PAD RMW padding** (`disq_hpad_rmw_padding.py`, `UV3_padding` / `EM_padding`): the UV3 / E→M actor is the `ADD_M_R` padding after the transmitter. Harness artifact.
- **SpecLFB non-load footprint** (`disq_speclfb_nonload.py`, `other:disq_non_load_footprint`): in-window events whose req is not `ld`. Out of scope.
- **check_ld RMW limm artifact** (`disq_check_ld_rmw_limm.py`, RL-10): ReCon RMW transmitter tainted and not forwarded; check_ld scored the leading `limm`. Checker artifact.
- **Reveal artifact in the twin** (`recon_reveal_artifact.py`, E2LT-3): the twin rerun shows `revealRequests > 0`. Harness artifact (main-run hit stays R-SA-13).

**Residue labels (no module, unexplained by design):** InvisiSpec `other_<struct>` (DIR, DTLB, L2, L1D footprints with no specld eviction), SpecLFB `other:<tags>` (`safe_other`, `unsafe1_filled`, `replayed_after_safe(...)`, `no_unsafe_line`), CleanupSpec `unattributed`, STT `other_stt` / `other`, ReCon `unexplained(...)` and the twin bookkeeping buckets.

**Not yet moved** (still only in `STAGE3_gem5/triage/diag/`, used by older per-run campaigns, not by the current classifiers): R-SA-12 physreg16, NDA forwarded producer, DoM xmit store forward, SPT br_x const / declassified condition, InvisiSpec store actor and D1 DTLB.

**DG-3 (Anna, 2026-11-15, option (i)).** `_dg3.normalize` exempts over_clean lines from the footprint checker's net-state outside-window filter before attribution: such a line moves from `net_state.outside_window` to `differing` and `inconsistent` / `decided` are recomputed with the checker's own set comparison. It cannot change `issued_in_window` (asserted). `check_footprint.py` itself is not edited, so new raw records still carry the old flag; classify.py re-derives it (`--no-dg3` turns this off).

  needs a forcing predicate (model/config change → owner approval).
  **Provenance:** `mdsToRead/OTB_GENERATION_GAP.md`; [[project_otb_generation_gap]].
